# Looking into github repos

## github.dev

Reference: [githubdev web based editor](https://docs.github.com/en/codespaces/the-githubdev-web-based-editor)

github.dev gives you VS Code’s editing and navigation tools directly in your browser, without cloning the repository or installing anything.

It’s useful for:
- Exploring code: browse the folder tree and keep several files open in tabs.
- Searching: search across files throughout the repository.
- maybe other stuff I don't know


In the URL, just replace github.com with github.dev.


## Deepwiki

DeepWiki generates AI-powered documentation from a GitHub repository and lets you ask questions about its code.

Reference: [deepwiki](https://deepwiki.com/).

In the URL, just replace github.com with deepwiki.com.

If the repository hasn’t been indexed yet, you can request it. Public repositories are free; private repositories require a Devin account.

It Helps you understand an unfamiliar codebase faster, without manually reading every file.
