# How to run

Complete [Installation](docs/installation/index.md), then choose your environment:

| Environment | Startup | Base navigation | Arm manipulation | Perception |
| --- | --- | --- | --- | --- |
| Simulation | [Gazebo](docs/startup/simulation/bringup.md) | [Teleoperation, mapping and Nav2](docs/startup/simulation/navigation/index.md) | [MoveIt GUI, Python and C++](docs/startup/simulation/manipulation/index.md) | [Cameras and AprilTags](docs/startup/simulation/perception/index.md) |
| Real hardware | [Available components](docs/startup/hardware/bringup.md) | [Teleoperation](docs/startup/hardware/navigation/index.md) | [MoveIt GUI, Python and C++](docs/startup/hardware/manipulation/index.md) | [Cameras](docs/startup/hardware/perception/index.md) |

Run Compose commands from `~/ROB4_Fraunhofer/curtmini_piper_containers`.
Real-robot mapping and autonomous navigation are still planned.
