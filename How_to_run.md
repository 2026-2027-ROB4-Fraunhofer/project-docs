# How to run

Complete [Installation](docs/installation/index.md), then choose a task in [Startup and walkthrough](docs/startup/index.md).
Run Compose commands from `~/ROB4_Fraunhofer/curtmini_piper_containers`.

- [Simulation startup](docs/startup/simulation.md)
- [Available real-hardware components](docs/startup/real_hardware.md)
- [Mapping](docs/startup/mapping.md) and [navigation](docs/startup/navigation.md)
- [Base teleoperation](docs/startup/teleoperation.md)
- Arm motion with [MoveItPy](docs/startup/moveitpy.md) or [C++](docs/startup/moveit_cpp.md)
- [Cameras](docs/startup/cameras.md) and [AprilTag detection](docs/startup/apriltags.md)
- [Tag poses in the map](docs/startup/tag_pose.md) and [Python navigation goals](docs/startup/nav2_python.md)
- [Standalone RViz](docs/startup/rviz.md)
- [Development workflows](docs/startup/development.md)
- [Troubleshooting](docs/startup/troubleshooting.md)

See [Explanation](docs/explanation/index.md) for project details and [Helpers](docs/helpers/index.md) for general tools.
